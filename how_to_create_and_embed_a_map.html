Guide: How to Create and Embed a Map

This guide shows you how to create a map, configure settings, format WordPress posts, and embed it into your website.

Step 1: Log in to the Admin Dashboard

  1. Open your browser. Go to your Admin Portal URL (example: http://localhost:5050/admin/).
  2. Click the Login with CERN SSO button.
  3. Log in using your CERN account.

Step 2: Create a New Map

  1. In the sidebar menu, click Maps.
  2. Click the Add New Map button in the top right.
  3. Enter a Display Name (example: Europe Collaboration).
  4. The system automatically creates a Map ID (example: europe-collaboration). You can edit this ID.
  5. Click Save. The dashboard will redirect you to the map editor page.

Step 3: Configure Map Settings

In the map editor page, configure these settings:

  1. Latitude, Longitude & Zoom: Use the sliders to set the initial starting position and zoom level of the map.
  2. Enable Clustering: Toggle this switch to group close markers into single circles when zoomed out.
  3. Filtering Rules (Optional):
    • Limit by Categories: Enter WordPress category names to show only posts from those categories.
    • Limit by Tags: Enter WordPress tag names to show only posts with those tags.
  4. Click Save Settings in the top right.

Step 4: Configure WordPress Posts

To show locations on your map, publish posts in WordPress containing coordinate data:

  1. Add Coordinates: Write the latitude and longitude in the WordPress post Excerpt box.
    • Format: latitude, longitude
    • Example: 46.2330, 6.0555
    Note: The tool parses and reads the first two decimal numbers it finds in the excerpt text.
  2. Featured Image: Assign a featured image to the post. This image displays as a thumbnail inside the marker popup.
  3. Categories & Tags: Set categories and tags on the post. These form the badge tags and categories inside the map popups and sidebar filters.
  4. Custom Website Link (Optional): By default, map popups link back to the WordPress post. To link to a custom URL instead:
    • Switch the WordPress editor to HTML view.
    • Add an element with id="website-url" containing the URL.
    • Example: <a id="website-url" href="https://cern.ch">Visit Website</a>

Step 5: Sync the Map

Your map automatically pulls new WordPress posts on a schedule. To sync immediately:

  1. In the sidebar, click Metrics.
  2. Click the Force Sync button.

Step 6: Embed the Map on Your Website

  1. In the sidebar, click Maps.
  2. Click Copy Embed Code next to your map.
  3. Paste the copied iframe code into your website's HTML source.

Iframe Code Example:

<iframe
  src="https://your-server.com/embed/?map=europe-collaboration"
  width="100%"
  height="500"
  frameborder="0"
  allowfullscreen>
</iframe>

Customizing the Map View (URL Parameters)

You can add parameters directly to the src URL of your iframe to change the map configuration on the fly:

Parameter Description Example
map The ID of the map to display map=europe-map
lat & lng Overrides the default map center coordinates lat=46.2&lng=6.0
zoom Overrides the initial zoom level (1 to 20) zoom=12
categories Filter map to these categories (comma-separated) categories=Labs,Offices
tags Filter map to these tags (comma-separated) tags=featured
clustering Enable/disable cluster grouping (1 = On, 0 = Off) clustering=1

URL Customization Example:

https://your-server.com/embed/?map=default&lat=46.2&lng=6.0&zoom=10&categories=Labs
